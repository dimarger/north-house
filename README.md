# NORTH & HOUSE

Premium real estate website built with React, Vite, React Router, JavaScript, CSS and Lucide React.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/data/properties.js` contains the property catalog data.
- `src/data/translations.js` contains EN/PL interface copy.
- `src/context/AppContext.jsx` stores language, saved properties and compare selections in `localStorage`.
- `src/pages` contains all routed pages.
- `src/components` contains reusable UI, filters, SEO and forms.
- `src/styles/styles.css` contains the visual system and responsive layout.
